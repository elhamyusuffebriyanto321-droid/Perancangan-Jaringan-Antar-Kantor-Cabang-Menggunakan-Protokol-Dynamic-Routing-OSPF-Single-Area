# Perancangan-Jaringan-Antar-Kantor-Cabang-Menggunakan-Protokol-Dynamic-Routing-OSPF-Multi-Area
Projek ini mensimulasikan jaringan sebuah perusahaan yang memiliki satu Kantor Pusat dan dua Kantor Cabang di kota berbeda, yang saling terhubung secara otomatis menggunakan protokol routing OSPF (Open Shortest Path First).

# 🧠 Gambaran Umum
Lab ini mendemonstrasikan jaringan perusahaan yang berbeda agar saling terhubung otomatis menggunakan protokol OSPF, simulasi menggunakan GNS3 sebagai Topologi dan Winbox untuk melakukan konfigurasi.
